# Archived discovery implementation

These files retain the acquisition replay, native collector, transport, frame-construction and sampling implementation for inspection. Machine-specific source paths were parameterized or normalized, and original file hashes are recorded in the export mapping. They are **not a self-contained A replay distribution**.

Execution additionally requires the original sealed acquisition response corpus, response manifests, prior-round rejection map, author recovery tapes, relevant configuration and original design/control manifests. The source corpus is not redistributed. The original driver expects that controlled archive layout; replacing raw bodies with newly fetched pages changes the experiment. The `GEWU_FIXED_ARCHIVE` setting identifies an independently prepared archive, not an installed production application.

Use root `score_results.py` to reproduce the published A calculations from the complete structured dataset without those acquisition bodies. Root `replay.py` is the tested portable wrapper for synthetic B/C only.
